# 💄 Beauty & Cosmetics E-Commerce System

ระบบเว็บไซต์ร้านค้าออนไลน์สำหรับจำหน่ายเครื่องสำอางและสกินแคร์ พัฒนาขึ้นเพื่อเป็นโปรเจกต์การเรียนรู้ในรายวิชาที่ประยุกต์ใช้หลักการเขียนโปรแกรมเชิงวัตถุ (**OOP - Object-Oriented Programming**) และการวิเคราะห์ออกแบบระบบเชิงวัตถุ (**OOAD**) ร่วมกับภาษา PHP, Bootstrap 5 และฐานข้อมูล MySQL (MariaDB)

---

## 🌟 ฟีเจอร์เด่นของระบบ (Key Features)

### 👤 ฝั่งลูกค้า (Customer Portal)
* **ระบบสมาชิก**: สมัครสมาชิก (`register.php`) และเข้าสู่ระบบ (`login.php`) พร้อมระบบตรวจสอบสิทธิ์
* **แคตตาล็อกสินค้า & ค้นหา**: หน้าแรก (`index.php`) แสดงรายการเครื่องสำอาง พร้อมช่องค้นหาชื่อสินค้า และปุ่มกรองหมวดหมู่สินค้า (ลิปสติก, บรัชออน, มาสคาร่า, รองพื้น/แป้ง, สกินแคร์) แบบ Sticky Bar เกาะติดหน้าจอ
* **ตะกร้าสินค้า (Shopping Cart)**: เพิ่มสินค้า ปรับลดจำนวน และคำนวณราคารวมอัตโนมัติผ่าน `CartClass.php`
* **ระบบชำระเงินและอัปโหลดสลิป**: กรอกข้อมูลที่อยู่ เบอร์โทรศัพท์ และแนบหลักฐานการโอนเงิน (Slip Upload)
* **ระบบตัดสต็อกอัตโนมัติ**: เมื่อลูกค้ายืนยันการสั่งซื้อ ระบบจะทำการหักลบจำนวนสต็อกสินค้าในฐานข้อมูลทันที
* **ประวัติการสั่งซื้อและสถานะ (Pop-up Modal)**: ตรวจสอบสถานะคำสั่งซื้อ (รอตรวจสอบ, กำลังจัดส่ง, ได้รับสินค้าแล้ว) ผ่านหน้าต่าง Pop-up สะดวกสบาย
* **ยืนยันรับสินค้า & พิมพ์ใบเสร็จ**: ลูกค้าสามารถกดยืนยันว่าได้รับสินค้าแล้ว และกดเปิดหน้า `receipt.php` เพื่อพิมพ์ใบเสร็จ/ใบกำกับสินค้าได้

### 🛠️ ฝั่งผู้ดูแลระบบ (Admin Dashboard)
* **จัดการรายการสินค้า (CRUD Products)**: เพิ่มสินค้าใหม่, แก้ไขรายละเอียด/ราคา/สต็อก, และลบสินค้า ผ่านหน้าต่าง Modal สุดเนียนตา
* **ตรวจสอบคำสั่งซื้อและสลิป**: ตรวจสอบรายการสั่งซื้อ ดูภาพสลิปโอนเงินจริงขนาดใหญ่, กดอนุมัติการจัดส่ง (✔️) หรือจัดการลบออร์เดอร์ (❌)

## 🗄️ โครงสร้างฐานข้อมูล (Database Schema)

ระบบใช้งานฐานข้อมูลชื่อ `ecommerce_db` ประกอบด้วย 4 ตารางหลักที่มีความสัมพันธ์กัน (Relational Database):
1. **`users`**: เก็บข้อมูลสมาชิกและสิทธิ์การใช้งาน (`customer` หรือ `admin`)
2. **`products`**: เก็บข้อมูลสินค้า รายละเอียด ราคา และสต็อกคงเหลือ
3. **`orders`**: เก็บข้อมูลคำสั่งซื้อ ที่อยู่ เบอร์โทร สถานะ และรูปสลิปโอนเงิน
4. **`order_items`**: ตารางกลาง (Junction Table) เชื่อมโยงรายการสินค้าที่สั่งซื้อเข้ากับคำสั่งซื้อแต่ละรายการ
